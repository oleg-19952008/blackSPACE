# Dark SPACE (Black SPACE server)

Сервер космической браузерной MMO-игры «Dark SPACE» (также известной как Black SPACE), написанный на **C# (.NET Framework 4.8)**. Проект реализует серверную часть игры: сетевое взаимодействие по TCP-сокетам, обработку игровых пакетов, логику карт, пользователей, кораблей, NPC-пришельцев и хранение данных в MySQL/MSSQL.

## Возможности

- 🚀 **Игровой сервер**: обработка подключений игроков через асинхронный TCP-сокет-листнер, чтение и отправка бинарных игровых пакетов.
- 🌌 **Карты и игровой мир**: управление картами (`Maps`), координатами, расстояниями, ящиками/лутбоксом (`Box`).
- 👤 **Пользователи и персонажи**: аккаунты, настройки, корабли (`Ship`), кланы (`Clan`), опыт, честь, ресурсы.
- 🛸 **NPC и боевая система**: справочник NPC-кораблей (`Ships`), ИИ-пришельцы с атакой и перемещением (`Aliens`, `AlienAttack`, `AlienMovement`), лазерное оружие, щиты, урон.
- 💾 **База данных**: встроенный менеджер БД (`MySQLManager`) с поддержкой MySQL и MSSQL — клиенты, адаптеры запросов, транзакции.
- ⚙️ **Сервисные компоненты**: консольные команды (`Console.cs`), логгер, менеджер настроек и боеприпасов, шифрование (`core.encrypt.cs`).

## Структура проекта

```
.
├── Program.cs                 # Точка входа, основная игровая логика и цикл сервера
├── Console.cs                 # Консольные команды управления сервером
├── Distance.cs                # Расчёты расстояний в игровом мире
├── core.encrypt.cs            # Шифрование/расшифровка данных
├── core/                      # Сетевой слой
│   ├── connection.cs          # Асинхронный TCP-листнер и обработка соединений
│   ├── packets.cs             # Формат и обработка игровых пакетов
│   └── mysql/                 # Менеджер базы данных (MySQL/MSSQL клиенты, адаптеры)
├── game/                      # Игровые сущности
│   ├── Users.cs               # Пользователи и их состояние
│   └── usersClass/            # Классы: Ship, Clan, Settings
├── serverGame/                # Логика игрового мира
│   ├── Maps.cs                # Карты
│   ├── Aliens.cs              # Пришельцы
│   ├── AlienClasses/          # ИИ: атака и перемещение
│   └── Box.cs                 # Ящики/лутируемые объекты
├── Assembly/                  # Вспомогательные модули
│   ├── AmmoManager.cs         # Управление боеприпасами
│   ├── Logger.cs              # Логирование
│   ├── Pet.cs                 # Питомцы
│   └── SettingsManager.cs     # Настройки сервера
└── Properties/, App.config    # Конфигурация .NET-проекта
```

## Требования

- Windows (проект собирается под x64)
- .NET Framework 4.8
- MySQL Server (или MSSQL) для хранения данных
- Visual Studio 2013+ / MSBuild для сборки

## Сборка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   ```
2. Откройте проект `Dark SPACE(Black SPACE server).core.csproj` в Visual Studio или соберите через MSBuild:
   ```
   msbuild "Dark SPACE(Black SPACE server).core.csproj" /p:Configuration=Release
   ```
3. Настройте подключение к базе данных (см. `App.config` и папку `core/mysql`).
4. Запустите собранный `Server.exe` — сервер начнёт принимать соединения клиентов игры.
